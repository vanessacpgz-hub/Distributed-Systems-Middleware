# Distributed Systems: Middleware Practice

Introduction to middleware in distributed systems, built in Python on Linux for the Distributed Systems course (Instituto Tecnológico de Aguascalientes).

REST (Flask), Pyro5, gRPC, RabbitMQ, Kafka and XML-RPC, each with its own server and client, plus a conceptual CORBA interface definition.

RabbitMQ and Kafka require their servers to be running locally.
